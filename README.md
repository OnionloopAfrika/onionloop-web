# OL Merchant

## Overview
OL Merchant is a merchant management system for the Onion Loop platform.

## Getting Started

### Prerequisites
- Node.js 14+
- npm or yarn

### Installation
```bash
npm install
```

### Running the Project
```bash
npm start
```

## Project Structure
```
ol-merchant/
├── src/
├── tests/
├── docs/
└── README.md
```

## Features
- Merchant registration and management
- Order processing
- Payment handling
- Analytics and reporting
